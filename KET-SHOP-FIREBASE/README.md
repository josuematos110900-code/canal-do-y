# KET SHOP — versão Firebase

Plataforma de venda de diamantes e passes **Free Fire** em Kwanzas: app Android (Java/XML, sem bibliotecas,
compatível com CodeAssist), painel administrativo Web e backend **Firebase** (Authentication, Cloud Firestore,
Cloud Storage e Security Rules).

Comece por **[documentation/README.md](documentation/README.md)**.
